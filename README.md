# مسابقة أجمل لقطة لأي معلم من معالم قطر

مدرسة هند بنت عتبة الإعدادية للبنات - قسم الحوسبة وتكنولوجيا المعلومات
آخر يوم للتسليم: الخميس 5/11

| الملف | وظيفته |
|---|---|
| `index.html` | صفحة المسابقة (تُنشر على Vercel) |
| `config.js` | رابط السكريبت وموعد الإغلاق |
| `poster.jpg` | ملصق المسابقة |
| `vercel.json` | إعدادات Vercel |
| `Code.gs` | كود Google Apps Script (يُلصق في script.google.com، وليس جزءًا من الموقع) |

الصفحة ترسل الصورة إلى Google Apps Script، والسكريبت يحفظها في مجلد «مسابقة أجمل لقطة» على Google Drive
ويسجلها في جدول «سجل المشاركات». المجلد يبقى خاصًا، ويُغلق النموذج تلقائيًا بعد موعد التسليم.
